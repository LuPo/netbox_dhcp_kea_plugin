# Guides

In-depth guides that go beyond the reference documentation to cover *how* and *why* to model specific DHCP configurations with this plugin.

- [Class-conditional option delivery](class-conditional-option-delivery.md) — modelling DHCP options that are only meaningful to specific device classes (wireless APs, IP phones, PXE clients, kiosks…), including the per-subnet and per-class value variation cases.
